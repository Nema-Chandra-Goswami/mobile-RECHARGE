# 📱 Mobile Recharge Management System

The **Mobile Recharge Management System** is a desktop-based application designed to manage mobile recharge operations efficiently.  
It provides a simple and user-friendly interface for handling customer recharges, maintaining records, and managing recharge plans.

This project demonstrates core concepts of **application development, database integration, and CRUD operations**.

---

## Features

- Add and manage mobile recharge records
- Customer information management
- Recharge plan selection
- Store and retrieve data from database
- Secure and structured data handling
- User-friendly desktop interface

---

## Tech Stack

- **Programming Language:** C#
- **Framework:** .NET (Windows Forms)
- **Database:** SQL Server
- **IDE:** Visual Studio
- **Architecture:** Layered / MVC-style approach

---

## Project Structure

- `Forms/` – Application UI screens
- `Database/` – SQL queries and database logic
- `Models/` – Data models
- `Controllers/` – Business logic
- `Assets/` – Resources and icons
